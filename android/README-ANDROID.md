# BRO CLIPPER AI - ANDROID

Aplicación Android independiente.

## Funciones previstas
- Pegar enlace de YouTube.
- Descargar contenido propio o autorizado.
- Analizar automáticamente el video.
- Seleccionar 2 o 3 momentos destacados.
- Crear clips verticales 9:16.
- Guardar los clips en Movies/BRO_CLIPPER.

La APK se considerará terminada cuando esté compilada y probada en Android.

La versión Python original se conserva intacta.
